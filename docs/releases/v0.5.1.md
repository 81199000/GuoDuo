# GuoDuo 0.5.1 · 首个公开版本

GuoDuo 是原生 SwiftUI 的第三方短剧客户端，适配 iPhone Duo 折叠屏、iPad 与普通 iPhone。安装包为**未签名 IPA**，需要自行签名安装。

## 看剧
- 推荐：多个片库拼成随机剧池，竖滑一屏一部，只放第 1 集，感兴趣点「看全集」
- 推荐按姿态选片：横屏 / 桌面半折看横屏片，竖屏 / 书本半折看竖屏片
- 发现、搜索、题材筛选，粘贴分享链接直达
- 片源：红果 / 西饭 / 河马

## 播放
- 竖滑切集、拖进度预览画面、长按加速、倍速、画中画
- 弹幕（位置可切）、本集热评
- 极简模式：返回键外圈显示进度，暂停时显示详情
- 听书模式：退出 App 后继续播放声音

## 折叠屏
- 桌面半折：上半屏视频，下半屏操作台（快进退、音量亮度、截图、选集、倍速等）
- 书本半折：右侧常驻选集；横屏右侧液态玻璃标签栏

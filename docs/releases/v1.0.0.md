# GuoDuo 1.0.0

## 全新首页
- 奈飞主题首页（默认）：大海报，整页底色跟着封面主色变；继续观看、我的追剧、今日热播 Top 10、各榜单一行一行横着滑。
- 顶部分区：全部 / 真人剧 / 漫剧 / AI 剧 / 系列剧 / 西饭 / 河马，按屏幕宽度自动排，放不下的收进「类别」。
- 往下滑分区栏收起，往上滑弹回。也可以在「设置 → 首页主题」切回红果主题（两列大卡）。

## 搜索
- 没输入时有「热门搜索」和「为你推荐」，推荐的剧点播放键直接开播。
- 打字联想带封面和热度；搜索结果都有封面；粘贴红果分享链接直接打开。

## 电视联动（GuoDuo TV）
- 「我的 → 设置 → 安装到电视」：手机自动找到家里的安卓电视，把 GuoDuo TV 装上。
- 「连接遥控器」：扫码或局域网自动发现电视，手机当遥控器用。
- 手机扫电视登录页上的二维码，用手机的红果账号确认，电视直接登录。
- 手机看到一半点「更多 → 投到电视」，电视从同一秒接着播；遥控器里点「接到手机继续看」再接回手机。
- 「我的」右上角加了扫一扫；长按 App 图标也能直接扫一扫、连接遥控器。

## 播放
- 黑边环境光：画面两侧透出画面颜色的光，设置里可调强弱或关掉。
- 「更多」面板改成液态玻璃；「铺满全屏」挪进「更多」里。
- 推荐页右侧按钮栏和首页菜单一样宽，进出推荐时有过渡动画。
- 分集评论显示真实昵称和头像，滑到底自动加载更多。

## 账号与设置
- 手机号 + 验证码登录；登录后同步推荐、云端观看记录、收藏、预约，观看记录按账号分开存。
- 设置页重新分组排版；新增「缓存管理」，封面和头像缓存到本地，不再每次重新加载。
- 关于页：版本、检查更新、开源致谢。
